Actors: Admin - Organizer - User (Guest)

The Organizer can do the following:

1 - Create / Edit / Publish events with multiple ticket types.

The Admin can do the following:

1 - View Organizers
2 - View Organizers Events
3 - Manage Organizers and Events

The Guest can:

1 - View upcoming events
2 - Buy tickets
3 - Return tickets
